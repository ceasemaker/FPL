# Design System Document

This document outlines the core design principles and specifications for our user interface.

## Branding & Colors

**Color Mode:** dark

**Primary Color:** The brand's most distinctive chromatic color, used for buttons, CTAs, and key interactive elements.
`#FFFFFF`

**Secondary Color:** A supporting color for less prominent UI elements, chips, and secondary actions.
`#8E8E93`

**Tertiary Color:** An additional accent color for highlights, badges, or decorative elements.
`#007AFF`

**Neutral Color:** A neutral base color for backgrounds, surfaces, and non-chromatic elements.
`#000000`

**Body Font:** inter
**Label Font:** inter
